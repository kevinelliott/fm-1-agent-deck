Agent Deck cheat sheet

Firmware 0.7 for the M-VAVE FM-1. Every action goes to the selected agent unless a chord names another one. The deck needs its daemon running on the computer.

Colours and key LEDs

Amber, blinkingBLOCKED: the agent is waiting on you
White, solidWORKING
Green, solid 2 sDONE: it just finished a turn
Red, fast blinkERROR
Grey, dim glowIDLE: waiting for input
Offno agent on this key

Answer an agent

RECapprove the prompt
SAVEapprove and don't ask again (blinks when offered)
FXdeny (Esc)
ENVinterrupt (Ctrl-C)
SELEnter
K2 K3Up / Down, Left / Right
LFOcycle the agent's mode (Shift+Tab)

Start and prompt

PLAYstart / continue; on an empty key, start a new agent there
PRESETSarm a prompt preset (shown on the footer)
SEQsend it; to a BLOCKED agent it is queued (Q)
SEQ held 1 srepeat mode: send again after every turn (R)
ARPauto-approve on / off for this agent (A)

Get around

Keys, SELECTpick an agent
K4next agent that needs you
HOMEGRID; again: list / boxes
EDITDETAIL; again: OUTPUT / INFO / DIFF
GLOAPPROVALS; again: the longest-waiting agent
ALGORITHMGRID, DETAIL, APPROVALS, MENU, ABOUT
K1scroll DETAIL; a page at a time in MENU
OCT− OCT+previous / next page of 27 slots
MASTERvolume of the sounds

Chords: hold a button, tap a key

REC + keyapprove that agent
FX + keydeny that agent
ENV + keyinterrupt that agent
PLAY + keystart that agent, or a new one on an empty key
SEQ + key Nsend preset N to the selected agent
SEL + key Nanswer option N of the prompt
SAVE + keymove the selected agent to that key
LFO + keymark / unmark that agent (+)
ARP + keyauto-approve on that agent

Everyone at once: hold GLO

GLO + RECapprove every BLOCKED agent
GLO + FXdeny every BLOCKED agent
GLO + ENVinterrupt every WORKING agent
GLO + SEQsend the preset to every IDLE / DONE agent
GLO + ARPauto-approve off everywhere
GLO + LFOclear the marks

While any agents are marked, these act on the marked ones only.

Knobs with a button held

PLAY + PRESETSwhich agent PLAY starts
SEQ + PRESETShow many times repeat mode sends
SEL + K1scroll DETAIL a page at a time
LFO + K4step through the marked agents

MENU: SELECT moves, SEL picks, FX backs out

THIS AGENTview, repeat, auto-approve, mark, mute, queue, commands, focus, copy reply, open folder
FLEETevery agent on one screen; mark all
NEW AGENTpick a CLI and a directory, optionally a new git worktree
SEND PROMPTsend now or queue; again; recent prompts; the presets
EVENT LOGwho blocked, finished, was approved
CLOSE AGENTclose the pane, after a yes / no
SETTINGSsounds, alert, nag, notifications, follow
Full reference, setup and the daemon's options: the README. Auto-approve checks prompts against a list of risky patterns (and an allow-list, if you set one); it is a text match, not a sandbox.
