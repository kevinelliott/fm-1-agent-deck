Agent Deck config editor

Edit the daemon's settings here and save the result as ~/.config/agtdeck/config.json on the computer the daemon runs on, then restart the daemon. Nothing leaves this page: it does not talk to your FM-1 or your computer, it only builds a file for you to download. Only what you change is written; everything else keeps the daemon's default.

Start from

The defaults, or a config you already have.

Prompt presets

PRESETS arms one, SEQ sends it; SEQ + key N sends number N. The label is what the screen shows. One line of text is a prompt; several lines are a pipeline, one step per finished turn.

Auto-approve

Regular expressions, one per line, case-insensitive, matched against what the agent wants to run and the prompt on screen. This is a text match, not a sandbox.
